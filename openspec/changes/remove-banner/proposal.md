# Proposal

## Why

Баннер (`banner.jpg`) в настоящее время отображается на каждой странице сайта (базовый шаблон `baseof.html` и шаблон главной `index.html`). Это визуальный элемент без функциональной нагрузки: нет ссылки, нет призыва к действию, только изображение. Удаление баннера сделает страницы чище и сосредоточит внимание посетителей на текстовом контенте (о терапевте, статьях, случаях из практики).

## What Changes

- Удалить секцию баннера из базового шаблона `layouts/_default/baseof.html` (и/или из `layouts/index.html`, если баннер рендерится там отдельно), чтобы баннер более не рендерился ни на одной странице.
- Убрать связанные CSS-классы (`.banner-section`, `.banner`, `.banner-image`, `.banner-overlay`, `.banner-role`) из `assets/css/custom.css`, если они не используются иначе.
- Удалить файл `static/images/banner.jpg` из репозитория (он больше не используется нигде).

## Capabilities

### New Capabilities

- `site-header`: управление отображением элементов заголовка сайта (включая баннер). Новое требование: баннер не рендерится ни на одной странице. Создаёт `specs/site-header/spec.md`.

### Modified Capabilities

—

## Impact

- `layouts/_default/baseof.html` — удаление HTML-разметки баннера
- `layouts/index.html` — возможная очистка, если баннер дублируется там
- `assets/css/custom.css` — удаление неиспользуемых стилей баннера
- Сборка через `hugo` и деплой на GitHub Pages — без изменений
